💎 Workflow 5: Premium & AI Matchmaker

Subscription flow, AI-powered people matching, private clusters, and payment integration

PRD — Aggilo Social Network — MONETIZATION
⚠️ Architecture Note (May 2026): This PRD describes the AI Matchmaker as a standalone agent. In the current Yantra 5-agent architecture, matchmaking is a Clio skill (connection_intro) — Clio handles all user-facing matchmaking conversations, orchestrating Scout and Atlas as needed. The Premium tier itself remains active: subscription flow, private clusters, preference learning, and credibility-gated creation are all in production. The flagship global "Single Source" cluster is a premium cluster. For the current agent architecture, see yantra/guides/agentic_workflow.html and clio/AGENTS.md.

Free vs Premium Comparison

Free

₹0 forever
  • ✅ Unlimited cluster creation
  • ✅ Unlimited cluster joining
  • ✅ Basic AI cluster suggestions (Scout)
  • ✅ Collaborative Clio Hub support
  • ✅ Feed + Chat in all clusters
  • ✅ Direct messaging
  • ✅ Text + image posts
  • ❌ No private AI matchmaker chat
  • ❌ No AI preference learning
  • ❌ No private premium clusters
  • ✅ Can see AI matchmaker questionnaires
  • ✅ Can join private premium clusters

Premium

₹300 /month
  • ✅ Everything in Free
  • ⭐ Private AI matchmaker chat
  • ⭐ AI learns your preferences over time
  • ⭐ AI suggests relevant people to connect with
  • ⭐ Create private premium clusters
  • ⭐ Questionnaires sent to potential matches
  • ⭐ Complete control over AI chat settings
  • ⭐ Priority Scout discovery
🔑 Key Design Decision: Free users CAN see questionnaires from premium users AND can join private premium clusters. This means the value of Premium reaches free users — creating a natural upgrade funnel when they want to initiate their own matchmaking.

Subscription Management

Event Handling
Subscription active Auto-renews monthly. User gets 24hr reminder notification before renewal.
Cancellation Premium features remain until end of billing period. Private clusters stay accessible.
Payment failure 3-day grace period with retry. After 3 days, downgrade to Free with data preserved.
Re-subscription All premium data (preference learning, private clusters) is restored.

⚡ Generalized Learning: AI learns preferences on a generalized basis — it doesn't track browsing behavior or external activity. It only learns from interactions WITHIN Aggilo: chats, questionnaire preferences, cluster joins, purpose/tag interests.

🔒 Private Premium Cluster Rules

Rule Detail
Created by Premium users only (via AI matchmaker)
Visible to Only invited members — never appears in search or suggestions
Who can join Free AND Premium users (must be invited via questionnaire match)
Content Same as regular clusters (feed + chat + DM)
Deletion Cannot be deleted (same as regular clusters)
Member removal Cannot remove members (same as regular clusters)
If creator downgrades Cluster remains accessible. No new private clusters can be created.
