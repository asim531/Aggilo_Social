⚡ Key Rule: Gender and Age gates make clusters completely INVISIBLE — the user doesn't even know they exist. This is privacy by design, not rejection. The "Oops!" screen only appears when accessing via a direct shared link.
🗣️ Clio & Observer Language Suggestion Behaviour (Phase 1): Language is a soft-match signal — no language gate is active in Phase 1 (except for Premium Clusters). However, the system proactively suggests language-specific clusters via two mechanisms:
1. Clio Intelligence: Clio may suggest creating/joining language-specific clusters when she detects high gravity of need. Clio also surfaces the language context of recommended clusters.
2. Observer Passive Detection: Aggilo Observer continuously monitors language distribution. If ≥8 members in a primary cluster share a secondary language (e.g., Telugu), AND ≥3 of them post in that language, Observer automatically queues a recommendation to spawn a Telugu-parallel instance of that cluster. There is no manual 'Request Language' button.

🌐 Public Gateway: The public cluster preview page is the primary "Internet Gateway".
1. Searchable Public Link: Every cluster has a unique, searchable link.

Leave & Rejoin Rules

stateDiagram-v2 [*] --> Discovered : User finds cluster Discovered --> Qualified : Passes qualification Discovered --> Blocked : Fails qualification Qualified --> Joined : Taps "Join" Joined --> Active : Posts / chats Joined --> Passive : Just browses Active --> Left : Taps "Leave" Passive --> Left : Taps "Leave" Left --> Rejoined : Qualifies again + taps "Rejoin" Rejoined --> Active Rejoined --> Passive Blocked --> [*] : Cluster invisible
Action Rules
Join Instant. No approval needed. User must pass qualification gates.
Leave User can leave at any time. Departure is silent.
Rejoin Allowed if user still qualifies. Previous posts visible. No cooldown.
Founder leaves Founder can leave but retains Founder badge. Cluster continues.
