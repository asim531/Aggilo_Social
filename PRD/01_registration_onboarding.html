Step-by-Step Details

0

Walkthrough Screens

4 swipeable slides introducing Aggilo's core value proposition: "Find your people through AI-powered clusters."

First-time only
1

Phone OTP Verification

User enters Indian mobile number (+91). Receives 6-digit OTP via SMS. Max 3 retry attempts. OTP expires in 5 minutes.

Required One-time cost: ₹0.50
2

Year of Birth + Gender

Year of Birth: Year selector. Cannot be changed later. Drives all AGGIL age-based matching.
Gender: Male / Female / Genderqueer. Used for privacy gating on clusters.

Required Immutable Year of Birth
3

Language Selection

Select primary + secondary languages. Pre-populated from phone settings. Multiple languages supported.
Clio uses this for matching: Language is a core AGGIL dimension — Clio prioritizes clusters where members share the user's languages and surfaces language-specific insights (e.g., "This cluster speaks mostly Telugu"). Language also influences Clio's adaptive register and cultural references.

Required Auto-detected
4

Nickname + Purpose & Tags

Nickname: AI-verified for uniqueness and appropriateness. Real name never exposed.
Purpose & Tags: Tell Clio what you're looking for (Purpose) and add Multiple Vibrant Tags (Hooks). Captures emotions and specific needs.

Required AI-verified nickname
5

Dashboard Landing

User lands on dashboard with AI-generated AGGIL Suggestions based on their year of birth, gender, location (from phone), and specific purpose/vibrant tags. Pre-seeded clusters visible.

AI Suggestions ready Onboarding complete

Data Captured During Registration

Field Type Mutable? Used For
Phone Number String (+91XXXXXXXXXX) No Authentication, OTP, unique identifier
Year of Birth Integer (YYYY) ❌ No (immutable) AGGIL age calculation, cluster eligibility, content maturation
Gender Enum (M/F/GQ) Yes AGGIL gender gating, privacy filtering
Languages Array of strings Yes Content discovery, cluster matching
Nickname String (unique) Yes (limited) Public identity, DMs, cluster posts
Purpose & Tags Array of strings (Vibrant Hooks) Yes AGGIL matchmaking, Scout topic discovery
Device Location Lat/Lng (if permitted) Dynamic AGGIL geography, GPS cluster discovery
📍 Location Note: Device location is requested but NOT required at registration. Users can set a named location (city/area) instead. GPS sharing is a separate opt-in for proximity-based cluster discovery.

Edge Cases & Error Handling

Scenario Handling
User enters age < 13 Block registration — COPPA / DPDPA compliance
Phone number already registered "This number is already registered. Log in instead?"
OTP not received after 60s Show "Resend OTP" button (max 3 resends)
Offensive nickname detected by AI "This nickname isn't acceptable. Try another." + AI suggests alternatives
No purpose/tags provided Allow with warning: "Telling Clio your purpose helps her find better clusters for you"
App killed during registration Resume from last completed step on next open
No internet during OTP Show offline message, retry when connected
