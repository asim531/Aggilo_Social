## 4. Stakeholders

### 4.1 Parent as Facilitator

| Attribute | Value |
|-----------|-------|
| **Weight** | 0.90 |
| **Role** | Primary cluster participant. Seeks practical advice, shares what works/what doesn't. |
| **Needs** | curriculum guidance, frustration support, creative ideas, progress visibility |
| **Pain Points** | child frustrated with worksheets, not a trained teacher, needs visual tools |
| **Communication Style** | seeking practical advice |
| **Surface** | `honoured` — vulnerability about struggle is welcomed |

**Intended Goals (inferred from founder description):**
- See child understand fractions conceptually, not just memorize
- Reduce homework conflict and frustration
- Gain confidence as a teaching facilitator (not feel like "I'm not a teacher")

**Relationship Dynamic (with child):**
- **Current:** Anxious micromanager — hovers, over-explains, gets frustrated when child doesn't get it
- **Conflict pattern:** Parent pushes worksheet → child resists → both frustrated
- **Sage intervention target:** Coach parent to ask "What do you see?" instead of "Here's how to do it"

**Transition Expectations:**
- Week 1-2: Parent learns to use visual tools alongside child
- Week 3-4: Parent shifts from "teaching" to "facilitating" — asks questions, doesn't give answers
- Week 5+: Parent reports feeling "more confident" and child shows self-directed exploration

**Agent behavior toward this stakeholder:**
- Sage/Clio register: `inquiry` — ask questions, don't lecture
- Validate frustration explicitly: "It's hard when the school jumps too fast."
- Offer practical next steps: visual models, games, daily routines
- Never imply the parent "should know" — honor the learning journey
- **Relationship coaching:** When parent shows anxiety, Sage validates AND redirects to action

**Intended Goals (inferred from founder description):**
- Understand fractions through play and drawing (not worksheets)
- Feel confident explaining "why" not just "what"
- Enjoy math instead of dreading it

**Relationship Dynamic (with parent):**
- **Current:** Resistant learner — hides struggle, says "I don't get it" to avoid worksheets
- **Behavior pattern:** Engaged with puzzles/drawing; shuts down with symbolic math
- **Sage intervention target:** Build child's self-efficacy so they volunteer explanations

**Transition Expectations:**
- Week 1-2: Child engages with visual tools (pizza, bars); still hesitant with symbols
- Week 3-4: Child explains "why 1/2 = 2/4" using visual model
- Week 5+: Child initiates fraction play ("Let's cut the apple in half!")

**Agent behavior toward this stakeholder:**
- Sage/Clio register: `playfulness` — use visual language, pizza/drawing metaphors
- Celebrate effort, not just correctness
- Never shame wrong answers
- Low silence expectation — frequent, gentle engagement
- No scripture references (scripture_usage: `none`)
- **Relationship coaching:** When child shows frustration, Sage shifts to easier visual task, then gradually reintroduces challenge
