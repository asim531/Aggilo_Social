Goal
- Implement backend realtime infrastructure for the four signals defined in REALTIME_ENGAGEMENT_LAYER.md: presence, composition (typing), arrival, and care reach-out handoffs.

Scope
- Backend channels, events, and auth for realtime; no frontend (covered by FE08).

Requirements
- Define channels/events:
  - `cluster:{id}:presence` — join/leave and heartbeat events with lightweight payload (user_id hash or anon member key; no PII).
  - `cluster:{id}:typing` — short-lived typing events (anonymized); auto-expire on backend after timeout.
  - `cluster:{id}:posts` — new timeline posts and Sage handoff cards; include minimal metadata for FE08 arrival pill.
  - `user:{id}:clio_handoffs` or equivalent — care reach-out handoff events for Clio FAB dot.
- Use Supabase Realtime or equivalent Postgres-based change feeds aligned with architecture.
- Enforce auth:
  - Only cluster members can subscribe to `cluster:{id}:*`.
  - Only platform/agents can publish handoff events.
- Rate limiting / flood protection for typing and presence heartbeats.
- Idempotency where applicable (e.g., dedupe duplicate presence join).

Dependencies
- F01 runtime_events table for audits/logging if needed.

Plan
- Design channel naming and message schemas for each signal.
- Implement server-side publisher helpers for posts, handoffs, and presence.
- Integrate with auth layer to gate subscriptions and publishing.
- Add rate limits and sensible TTLs for typing events and stale presence cleanup.
- Write tests/simulations for cluster presence, typing burst, arrival pill events, and care handoff.

Files to Touch
- `apps/api/src/realtime/channels.ts`
- `apps/api/src/realtime/publishers.ts`
- `apps/api/test/realtime/*.test.ts`

Validation
- Member subscribed to cluster channel receives presence/typing/post events for that cluster only.
- Typing events auto-expire; offline clients cleaned up.
- Care handoff events only delivered to intended member and logged.

Risks & Mitigations
- Risk: noisy channels impact perf. Mitigate with compact payloads, rate limits, and server-side aggregation.
- Risk: auth leakage. Strictly validate cluster membership and user identity per subscription.

Out of Scope
- Frontend realtime UX (FE08).
- Long-term analytics on realtime events.
