Goal
- Build admin dashboard UI for Observer findings, moderation reports, tool proposals, prompt updates, **evolution proposals, spawn proposals, and composition visualization** with approve/reject flows, **plus Soul Manifestation Panel (per-recipient), Voice Preview, and Persona Override Manager**.

Scope
- Frontend admin screens/components; wire to existing APIs.
- **Expanded:** Six new panels for cluster-level adaptive management.

Requirements
- Sections: Critical/High/Medium/Low; By Domain (11 domains); Pending Approvals.
- Each finding row: title, severity, suggested action, approve/reject buttons (approve triggers job/API; reject archives).
- Reports section: list moderation reports with status update controls.
- Tool proposals: list platform/cluster tools with status and approve/reject.
- Prompt updates (Observer stewardship): show pending updates with veto window countdown and apply/deny.
- **Soul Manifestation Panel (per-recipient):**
  - Display current **per-recipient map** (`default`, `parent_as_facilitator`, `child_as_learner`, etc.)
  - Inline edit per recipient key (admin only)
  - "Regenerate from Genesis" button
  - Audit history table (reads `soul_manifestation_audit`)
  - **Per-recipient Voice Preview:** Generate sample Clio greeting and Sage post for each recipient type
- **Voice Preview Panel:**
  - Generate sample Clio greeting using current L1+L2+L3 stack per recipient (lightweight LLM call, ≤2K tokens)
  - Generate sample Sage post using same stack
  - Display with "Soul compliance check" badge
  - "Adjust calibration" button → opens inline editor
- **Persona Override Manager:**
  - List pending overrides
  - Approve/reject with reason
  - Preview merged persona before approval
- **Evolution Panel (NEW):**
  - Show active evolution proposals with cost, tier, evidence, jarringness score
  - Approve/reject/queue proposals
  - Show evolution history (applied changes with outcome verdict)
  - Show reversal queue (changes that worsened → propose undo)
  - Display capacity budget: base 100, actual, consumed, remaining for current week
  - Show composition trend chart (30-day tag weight changes)
- **Spawn Panel (NEW):**
  - Show active cluster spawn proposals with confidence, link type, estimated member count
  - Approve/reject/modify proposals
  - Show linked clusters (sequel/spinoff/sibling) with member flow
  - Show spawn history
- **Composition Visualization (NEW):**
  - Radial/pie chart of `inferred_composition` tag weights
  - Stakeholder map (roles, needs, pain points)
  - Feature spawn candidates (spawned vs pending)
  - Vibe characterization summary
  - Agent maturity indicator
- **Ecosystem Health Panel (NEW):**
  - Display current `ecosystem_phase` (Seed / Sprout / Canopy) with phase transition history
  - Success model dimensions table: id, name, weight, confidence, source, performance score, status
  - Inline weight editor (with floor enforcement — cannot reduce below floor_weight)
  - Dimension performance charts (time-series, 30-day trend)
  - Anomaly inbox: Observer-flagged anomalies with severity, description, recommended action
  - Admin review checklist for `pending_admin_review` ecosystems
  - Revision history: all past weight changes with rationale
  - "Add dimension" button (creates proposal, routes to Governor)
  - "Deprecate dimension" button (marks deprecated, preserves history)
  - Health score gauge (0–1, computed from weighted dimension performance)
  - Floor weight warnings: red highlight if any dimension is at or below floor
- Access control: admin-only route guard.

Risks & Mitigations
- Risk: action spamming. Add disable while pending.
- Risk: data volume. Paginate and filter.
- **Risk: Voice Preview LLM call slow. Cache preview results and invalidate on profile change.**
- **Risk: composition charts complex. Use lightweight chart library (e.g., recharts).**
- **Risk: ecosystem time-series data volume. Aggregate to daily resolution; raw data in `ecosystem_health_logs` table.**
- **Risk: weight editing without context. Show dimension rationale and measurement trend before allowing edit.**

Out of Scope
