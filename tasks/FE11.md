Goal
- Implement the member-facing "founding feedback" modal described in `AGENT_COMMUNICATION_CONTRACT.md` Pattern 7, so founding members can confirm whether the created cluster matches their intent.

Scope
- Frontend React components and wiring to existing backend endpoints; no schema changes.

Requirements
1. Badge & entry point
   - Add a persistent, dismissible badge in cluster chrome for eligible founders: "Clio has a note for you".
   - Clicking the badge opens the founding feedback modal.
   - Badge is shown only while `founding_feedback_status` is `pending` for this member/cluster **and** the founding member has at least lightly engaged with the room (for example, viewed the home once or scrolled the Timeline), so it does not appear on first paint.

2. Modal states (five-phase model)
   - Implement UI states matching the spec:
     - `opening` → `ready` → `sending` → `ack` → `badge_offer`.
   - Show clear loading/disabled states during `sending`.
   - On network error, show a friendly retry line (no stack traces).

3. Response capture
   - Present the approved cluster description and a concise summary of how the spec interprets the member's intent.
   - Provide response chips: **"Yes, this feels right"**, **"Mostly right, a few tweaks"**, **"Not quite the right shape"**.
   - Send the selected response + optional short comment to backend via an existing or new endpoint (as defined in B-tasks).
   - Update local state to hide the badge once an explicit response is recorded.

4. UX constraints
   - Modal is **user-invoked only** (no auto-open on page load).
   - If user selects "Not now", close modal but keep badge visible.
   - Language should avoid protocol-disclosure; talk about "how this room feels" and "what it’s for", not internal pipelines.
   - After a response is recorded, show a brief closing line such as: "Thank you. We use this to tune the room, not you." to reinforce that the person is not under evaluation.

Files to Touch
- `apps/web/src/components/cluster/FoundingFeedbackBadge.tsx` (new)
- `apps/web/src/components/cluster/FoundingFeedbackModal.tsx` (new)
- `apps/web/src/screens/cluster/ClusterPage.tsx` (mount badge + modal)

Validation
- Manual: create a cluster via the generic path, log in as founding member, see badge, open modal, submit a response, verify badge disappears.
- Manual: click "Not now" → modal closes, badge remains; re-open works.
- QA03 scenarios reference this modal as the closing surface of the intake pipeline.
