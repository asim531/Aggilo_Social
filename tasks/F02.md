Goal
- Create database schemas for llm_routing_config and llm_operation_keys to support dynamic routing and budgeting.

Scope
- Migrations and seed data; no routing logic changes.

Requirements
- Tables:
  - llm_operation_keys: op_key (PK), agent, description, default_model, latency_target_ms, cost_ceiling_usd, reliability_hint.
  - llm_routing_config: id, op_key FK, provider, model, temperature, max_tokens, priority (primary|secondary|overflow), active boolean, created_at.
- Seed op_key rows for Clio, Sage, Atlas, Scout key operations.
- Indexes on op_key + active.

Dependencies
- None.

Plan
- Write SQL migration for both tables with indexes.
- Seed initial op_key rows and default routing entries.
- Document op_key list in comments/seed.

Files to Touch

- Seed file if used

Validation
- Migration runs clean; selecting seeded op_keys shows defaults.

Risks & Mitigations

Out of Scope
