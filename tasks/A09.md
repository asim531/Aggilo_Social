Goal
- When a cluster has an active persona override, merge its vocabulary/phrases into L2 before the global persona.

Scope
- Runtime persona resolution and merge logic.

Requirements
- Implement `getPersonaOverride(clusterId)` → returns active override or null
- Implement `mergePersonaOverride(globalPersona, override)` → merges `recurring_phrases`, `words_never_used`, `emoji_rules`
- Update Clio builder: call merge after loading global persona, before token counting
- Update Sage builder: same merge step
- Add fallback chain: global persona → override → demographic default → anchor fallback
- Validation: override cannot introduce Soul-prohibited phrases

Dependencies
- A01 (Clio prompt builder with veto handling)
- A08 (soul manifestation generation)
- B13 (migration 022 for cluster_persona_overrides table)

Plan
1. Implement `persona-override-merger.ts` with merge logic and prohibition check
2. Wire into Clio builder L2 assembly
3. Wire into Sage builder L2 assembly
4. Add fallback chain for missing persona
5. Add unit tests for merge, validation, and fallback

Files to Touch
- `apps/api/src/lib/prompts/persona-override-merger.ts`
- `apps/api/src/services/clio.ts`
- `apps/api/src/services/sage.ts`

Validation
- Test: cluster with override adding `recurring_phrases: ["Let's unpack this"]` → phrase appears in prompt
- Test: cluster with override banning "spiritual" → word absent from prompt
- Test: inactive override (status != 'active') → skipped, global persona used

Risks & Mitigations
- Risk: merge produces token bloat. Mitigate with token ceiling enforcement.
- Risk: prohibited phrase injection. Mitigate with validation against Soul prohibition set.

Out of Scope
- Admin UI for override creation (in AD02); Genesis Engine profile generation.
