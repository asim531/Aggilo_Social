Goal
- Provide admin UI to manage persona lifecycle (draft→review→approved→active; revoke) with audit trail, **plus cluster-level persona override approval workflow**.

Scope
- Admin screen/components; uses existing persona files/metadata.
- **Expanded:** Cluster-level override governance with `draft` → `review` → `approved` → `active` workflow.

Requirements
- List personas with status, approved_by, last_reviewed.
- Actions: Approve (review→approved), Activate (approved→active, only one per demographic active), Revoke (active→review), Reject (review→draft with feedback).
- Record reviewer and timestamp; show history.
- Enforce one active persona per demographic; fallback persona highlighted.
- **Cluster Persona Override Governance:**
  - List cluster overrides by status (pending, review, approved, active)
  - Approve/reject with reason text
  - Preview merged persona before approval (shows global + override combined)
  - Audit trail per override (who created, who approved, when)
  - Link to Soul Manifestation Panel for context

Dependencies
- Persona metadata storage; op-key schema for routing if tied; admin auth.
- **B14 (API routes for persona_override CRUD).**

Plan
- Build admin personas page with table and action buttons.
- Wire actions to backend endpoints (or stub if pending), optimistic update with error rollback.
- Add history display per persona.
- **Add cluster override tab with approval workflow and merged preview.**
