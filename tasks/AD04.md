Goal
- Provide separate admin dashboards for `platform_admin`-created vs `user`-created premium clusters, plus vault management UI with security check workflow.

Scope
- Admin dashboard views; vault add/remove with security check UI.

Requirements

1. **Platform Operations Dashboard** (`creator_type: platform_admin` clusters):
   - Full cluster lifecycle management (create, edit, pause, deprecate)
   - Subcluster tree visualization (parent → children hierarchy)
   - Cross-cluster link management (create/remove links)
   - System-wide vault access and audit (view all vaults, audit security_check_status)
   - Evolution proposal review (approve/reject with reason)
   - Token budget allocation across cluster network
   - Cluster spawn proposal review and approval
   - Member migration paths between linked clusters

2. **User Premium Dashboard** (`creator_type: user` clusters):
   - Single cluster management (edit name, description, AGGIL settings within platform rules)
   - Member management (≤50 members, invite, remove, role assignment)
   - Vault manager:
     - Add items (upload file or enter text)
     - Security check confirmation checkbox: "I confirm this complies with Aggilo policies"
     - View security check status (pending/approved/rejected/flagged)
     - View rejection reason if rejected
     - Remove items (with confirmation + security check re-confirmation)
     - Storage usage bar (X MB / 100 MB used)
     - Item count (X / 50 used)
   - Basic analytics (member count, engagement rate, active members last 7 days)
   - Billing/subscription status (if paid premium)
   - Support tickets (create, view status)
   - Genesis probe conversation review (view questions asked, answers given, confidence deltas)
   - Cannot access: subcluster management, cluster spawning, cross-cluster links, evolution proposals

3. **Vault Security Check UI**:
   - Upload flow:
     - Select item type (reference, example, worksheet, image, document, link, code_snippet)
     - Enter title + content or upload file
     - Mandatory checkbox: "I confirm this content complies with Aggilo policies and does not violate any cluster rules or security standards"
     - Submit → system runs automated check → show result (approved/rejected/flagged)
   - If rejected: show specific reason (content safety, policy violation, copyright, malware)
   - If flagged: show "Queued for admin review" status
   - Audit view: history of all vault operations with timestamps and outcomes

4. **Dashboard Routing**:
   - Aggilo admin users see Platform Operations Dashboard by default
   - Can switch to User Premium Dashboard view (read-only) for any cluster
   - Regular users (cluster founders) see User Premium Dashboard for their cluster only
   - URL pattern: `/admin/clusters/:clusterId` — dashboard adapts based on `creator_type` + user role

Validation
- Platform admin can view and manage admin-created cluster + all subclusters
- User founder can manage own cluster vault, cannot access subcluster/spawn features
- Security check blocks submission if checkbox not checked
- Rejected vault items show clear reason to founder
- Flagged items appear in platform admin review queue

Risks & Mitigations
- Risk: vault file upload size abuse. Mitigate: client-side + server-side size validation (5 MB max for user clusters).
- Risk: security check UI feels burdensome. Mitigate: clear explanations, one-click confirmation, fast automated response (<2s).
- Risk: founder confusion about dashboard capabilities. Mitigate: clear capability callout box showing "Your cluster: standalone, no subclusters" etc.
