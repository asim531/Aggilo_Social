Goal
- Add schemas for platform_tools and cluster_tool_enablements, and a loader stub for agents.

Scope
- DB migrations + backend loader stub; no UI.

Requirements
- Tables:
  - platform_tools: id, name, version, description, scope (platform|cluster), status (pending|approved|active|retired), proposed_by_agent, created_at, activated_at, retired_at.
  - cluster_tool_enablements: id, cluster_id, tool_id FK, enabled_by_admin, enabled_at, status.
- Auto-promotion flags can be stored as status or separate field if needed later.
- Loader stub: service to fetch active tools for cluster_id (joins enablements + platform active tools) for agents to import.

Dependencies
- None.

Plan
- Add migrations for both tables with indexes on status and cluster_id.
- Implement loader function in `cluster-tools` service returning tool descriptors.
- Tests for schema and loader selection logic.

Files to Touch

- `apps/api/src/services/cluster-tools.ts`
- Tests under `apps/api/test/cluster-tools.test.ts`

Validation
- Creating tool + enablement returns in loader for cluster; retired tools excluded.

Risks & Mitigations

Out of Scope
