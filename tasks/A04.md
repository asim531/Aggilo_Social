Goal
- Implement Sage→Atlas brief protocol with up to 3 rounds and zero-content synthesis path, **calibrated to cluster soul manifestation profile**.

Scope
- Atlas service handling briefs, rounds, and synthesis flag; logging.
- **Expanded:** Brief generation adjusts content tone based on `soul_manifestation_profile.primary_register`.

Requirements
- Brief structure per spec: cluster_id, brief_version, issued_by, aggil_segment, purpose, arc_phase, format_preference, existing_pulse_topics, freshness_threshold_hours, content_count_requested, variant, refinement_feedback, poll_rl_context.
- **Add `soul_manifestation_profile` to brief inputs so Atlas can calibrate tone.**
- Rounds: max 3. Sage issues brief; Atlas returns cards with relevance scores; Sage may send refinement feedback for next round; after round 3, finalize or synthesize.
- Zero-content protocol: if no cards after all rounds, set synthesis_mode=true with transparent framing string; persist reason.
- Log refinement history for next cycles.
- **Register-aware content:**
  - `warmth` → inviting, question-oriented hooks
  - `rigor` → analytical, evidence-oriented hooks
  - `inquiry` → curious, open-ended hooks
  - `reverence` → contemplative, scripture-aware hooks
  - `playfulness` → experimental, energetic hooks

- Add tests: normal 2-round flow, max rounds, synthesis path.
- **Add tests: register-aware tone (warmth vs rigor) in generated hooks.**
