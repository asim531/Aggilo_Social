Goal

Scope
- Frontend components/hooks for presence, typing indicator, arrival pill, care reach-out FAB dot.

Requirements
- Presence: show live count in header + green dots on member posts; channel `cluster:{id}:presence`.

Dependencies
- Realtime channels (B11); clio_handoff_greetings data; use hooks for subscriptions.

Plan
- Implement presence context/provider to dedupe subscriptions.
- Add typing indicator hook with throttle/timeout.
- Add arrival handlers to feed hook for posts/handouts/chatbox events.
- Add FAB dot tied to handoff subscription + initial fetch.
- Tests for rendering under simulated events and offline/reconnect.
