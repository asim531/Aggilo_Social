Goal
- Add tables required for Observer autonomous stewardship (Channel 1) per PLATFORM_AGENCY, **including evolution proposal types, per-recipient profile updates, and validation Rule 10**.

Scope
- Migrations only.
- **Expanded:** Observer can now propose `soul_manifestation_shift`, `persona_override_activation`, `manifestation_per_recipient_adjustment`, and evolution proposals as Tier 1/2 actions.

Requirements
- Tables:
  - observer_prompt_updates: id, agent, layer (2|3|4), content JSONB/text, ttl_expires_at, veto_until nullable, created_at.
    - **update_type extended: `soul_manifestation_shift`, `persona_override_activation`, `manifestation_per_recipient_adjustment`, `cultural_resonance_update`, `composition_recalculation`, `stakeholder_reinference`, `feature_proposal`, `tone_adjustment`, `cluster_spawn_proposal`, `reversal`, `ecosystem_adaptation`**
  - clio_observer_signals: id, user_id nullable, cluster_id nullable, signal JSONB, ttl_expires_at, created_at.
  - observer_cluster_context: id, cluster_id, context JSONB, version, created_at.
    - **context JSONB now includes: `inferred_composition_snapshot`, `stakeholder_snapshot`, `evolution_history`, `suppressed_actions`, `ecosystem_health_snapshot`**
  - **ecosystem_health_reports: id, cluster_id FK, report_type (health_score|anomaly_flags|dimension_drift|latent_need), report JSONB, severity (low|medium|high|urgent), status (open|reviewed|resolved), created_at, updated_at**
    - **report JSONB includes: health_score, dimensions_evaluated, anomalies, latent_needs, recommended_action**
  - cluster_prompt_versions: id, cluster_id, agent, layer, version, created_at.
- Indexes on agent/layer, ttl_expires_at for expiry sweeps.
- **Validation Rule 10: Cannot modify `soul_manifestation_profile` (any recipient key) in a way that contradicts L1 Soul prohibitions.**
- **Tier 1 actions: `soul_manifestation_shift`, `manifestation_per_recipient_adjustment`, `tone_adjustment`, `reversal` (reversible, one cluster).**
- **Tier 2 actions: `composition_recalculation`, `stakeholder_reinference`, `feature_proposal` (broader effect, staged).**
- **Tier 3 actions: `cluster_spawn_proposal` (structural — requires admin approval).**
- **New Tier 1/2/3: `ecosystem_adaptation`** — Tier 1 (weight change ≤10%), Tier 2 (new dimension), Tier 3 (purpose drift / spawn recommendation)

**CIM Measurement Requirements (for ecosystem dimensions):**
- `cim.learner_state.mastery_depth`: Tracks conceptual understanding across representations (visual → verbal → symbolic)
- `cim.sentiment.parent_self_efficacy`: Measures confidence from post sentiment analysis
- `cim.engagement.child_voluntary_return_rate`: Tracks voluntary child re-engagement
- `cim.network.parent_support_density`: Measures reply density on frustration posts
- **Note:** These CIMs are **cluster-type-specific**. Generic CIMs (post velocity, composition) remain unchanged.
