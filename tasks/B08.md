Goal
- Add database schemas to support Genesis Engine (intake, specs, reports) **and fluid adaptive architecture tables** (feature proposals, evolution, spawn, per-recipient soul manifestation).

Scope
- Migrations only; no engine logic yet.
- **Expanded:** Includes Migration 022 (per-recipient soul_manifestation_profile, cluster_persona_overrides, soul_manifestation_audit, RLS policies).
- **New:** Migration 023 (fluid adaptive tables: cluster_feature_proposals, evolution_proposals, evolution_budget_log, cluster_spawn_proposals, cluster_links).

Requirements
- Tables:
  - cluster_intent_responses: id, cluster_id FK, user_id FK nullable, source (founder_description|admin_input|scout_inference|member_refinement), **description TEXT** (free-text, replaces questionnaire), created_at.
  - cluster_intake_drafts: id, source (waitlist|scout|clio), payload JSONB, version int, status (draft|refined|approved), created_at, updated_at.
  - cluster_intake_refined: id, draft_id FK, reviewer_agent (adversarial), diff JSONB, created_at.
  - cluster_specs: id, cluster_id FK nullable (pre-creation), spec JSONB, version int, status (proposed|validated|live|drift_detected), created_at.
    - **spec JSONB includes: `inferred_composition`, `stakeholders`, `feature_spawn_candidates`, `vibe_characterization`, `soul_manifestation_profile` (per-recipient map), `cluster_spawn_risk`, `agent_maturity`, `sub_surface_proposal`**
  - **cluster_ecosystem_specs: id, cluster_id FK UNIQUE, ecosystem_spec JSONB, status (pending_admin_review|active|paused|deprecated), ecosystem_phase (seed|sprout|canopy), phase_transition_history JSONB, created_at, updated_at**
    - **ecosystem_spec JSONB includes: `ecosystem_type`, `purpose_alignment`, `success_model`, `progression_model`, `tool_requirements`, `introspection_targets`**
  - **ecosystem_health_logs: id, cluster_id FK, dimension_id, performance_score (0.0–1.0), health_score (0.0–1.0), anomaly_flags JSONB, measured_at, created_at**
    - Time-series table for ecosystem dimension performance tracking
  - cluster_genesis_reports: id, cluster_id FK, report JSONB, status, created_at.
    - **report JSONB includes `soul_manifestation_findings` for introspection drift**
  - cluster_persona_overrides: id, cluster_id FK, override_type, persona_content JSONB, status, approved_by, created_at, updated_at
  - soul_manifestation_audit: id, cluster_id FK, profile JSONB (per-recipient map), changed_by, reason, created_at
  - **cluster_vault_items: id, cluster_id FK, item_type, title, content, file_url, metadata JSONB, uploaded_by FK, security_check_status, security_check_reason, alignment_check_status, alignment_score, alignment_questions JSONB, alignment_reason, created_at, updated_at**
    - Stores cluster-specific vault content for agent reference
    - `security_check_status`: pending | approved | rejected | flagged
    - `alignment_check_status`: pending | approved | rejected | questions_pending
    - Max 50 items / 100 MB for user-created; 500 items / 500 MB for admin-created
  - **cluster_feature_proposals: id, cluster_id FK, feature_id, feature_type, proposal_source, probability, confidence, trigger_description, evidence, ui_placement, status, admin_decision fields, created_at, updated_at**
  - **evolution_proposals: id, cluster_id FK, proposal_type, tier, cost, evidence, confidence, jarringness_score, status, admin_approved fields, implemented_at, outcome_verdict, created_at, updated_at**
  - **evolution_budget_log: id, cluster_id FK, week_start, base_capacity, tier_multiplier, actual_capacity, consumed, created_at**
  - **cluster_spawn_proposals: id, parent_cluster_id FK, proposed_cluster_name, purpose_statement, link_type, inferred_composition, stakeholders, soul_manifestation_profile, feature_spawn_candidates, demographic_guardrails, migration_path, evidence, confidence, status, admin_decision fields, created_at, updated_at**
  - **cluster_links: id, parent_cluster_id FK, child_cluster_id FK, link_type, created_at**
  - **genesis_probe_responses: id, cluster_id FK, probe_round int, question TEXT, answer TEXT, targeted_dimensions JSONB, confidence_before JSONB, confidence_after JSONB, created_at**
    - Stores all adaptive probing Q&A for premium cluster Genesis
    - `targeted_dimensions`: list of dimension IDs this probe aimed to clarify
    - `confidence_before`: JSONB map of dimension → confidence before this round
    - `confidence_after`: JSONB map of dimension → confidence after this round
  - **cluster_activity_log: id, cluster_id FK, event_type VARCHAR(64), event_data JSONB, actor_type VARCHAR(32), actor_id UUID, inference_result JSONB, timestamp TIMESTAMPTZ NOT NULL, created_at**
    - Event types: genesis_probe, spec_change, feature_spawn, vault_add, vault_alignment, spawn_proposal, admin_decision, phase_transition, budget_change, member_joined, member_left
    - `timestamp`: server-generated, millisecond precision, ISO8601 with timezone
    - Supports time-series queries (range scans, ORDER BY timestamp DESC)
    - Used by Observer for drift detection; used by Sage for cluster context
  - **member_activity_log: id, cluster_id FK, member_id FK, event_type VARCHAR(64), event_data JSONB, cim_signal JSONB, inference_result JSONB, timestamp TIMESTAMPTZ NOT NULL, created_at**
    - Event types: tool_use, stage_complete, agent_interaction, sentiment_signal, error_pattern, help_request, vault_reference, progress_milestone
    - `timestamp`: server-generated, millisecond precision, ISO8601 with timezone
    - Agent queries use `ORDER BY timestamp DESC` for chronological member context
    - Inference pipeline: periodic LLM summarization → stored inference → used by Genesis/Observer
  - **cluster_fit_decision: id, founder_id FK, searched_dimensions JSONB, matches_found JSONB, decision VARCHAR(32) CHECK (decision IN ('join_existing', 'create_new', 'more_matches')), chosen_cluster_id FK nullable, timestamp TIMESTAMPTZ NOT NULL, created_at**
    - Logs Genesis cluster fit assessment decisions
    - `matches_found`: array of {cluster_id, match_score, cluster_name, member_count, activity_level}
  - **ALTER TABLE clusters: ADD COLUMN creator_type VARCHAR(32) DEFAULT 'user' CHECK (creator_type IN ('platform_admin', 'user'))**
    - Immutable at creation; determines cluster capabilities and vault limits
  - **ALTER TABLE clusters: ADD COLUMN service_mode VARCHAR(32) DEFAULT 'individual' CHECK (service_mode IN ('individual', 'group', 'hybrid'))**
    - Inferred by Genesis; determines social layer default and UI surfaces
- Indexes on status, cluster_id, parent_cluster_id, timestamp (for time-series queries).
- **RLS policies for all new tables.**
- **validate_soul_manifestation_profile() SQL function — validates per-recipient map (iterates all keys).**
