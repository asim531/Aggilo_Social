Core Engine

The AGGIL Engine — 5 Matching Parameters

Every cluster is defined by five parameters. Post-spawn, core parameters (Age, Gender, Geography) become immutable to protect existing members.

U-Shaped Scoring

Cluster specificity is scored on a U-curve: hyper-specific clusters (e.g., "Female ML researchers, Gachibowli, 22-26, Telugu") and fully global clusters (e.g., "The Single Source") both score high. Vague "mediocre middle" clusters are penalised — intentionality is the signal.

Cluster Lifecycle

Cluster Creation, Arc, and Rules

Creation

Two Paths

  • Find My People: User describes a need → Clio evaluates → cluster spawned when density threshold met
  • Make Your Crowd: Founder has existing people → Clio evaluates credibility → room built if vision is real
Post-Spawn Protection

Immutability Rules

  • Age, Gender, Geography locked once first member joins
  • Interest/Description: refinement only via Sage proposal → Clio scope test
  • Scope test: would a member who joined on the original description still feel they're in the right place?
  • Clio will refuse harmful edits even from Founders
Clio Arc (A-E)

Cluster Presence

  • A (Empty): Clio holds space. 1 Atlas content card. Compose invitation. No "Welcome!"
  • B (First Voice): First-post ack within 60s. Then 24h silence.
  • C (Low): 1 re-engagement post per 72h
  • D (Active): Passive. Responds only when addressed.
  • E (Thriving): One private msg to Founder. Then silent permanently.
Sage Arc (A-E)

Growth Guidance

  • A→B: ≥3 members posted, ≥2 replied to each other (5 day min)
  • B→C: Friction navigated, shared references appearing (7 day min)
  • C→D: Voluntary personal context sharing (7 day min)
  • D→E: Members initiating without Sage prompts (14 day min)
  • Regression possible: D/E→C if 14 days silence
Privacy Architecture

Nickname-Based Identity & Privacy-by-Design

Identity

Nickname Anonymity

All cluster activity uses nicknames. Real-world identity (name, email, phone) is decoupled from persona/cluster activity. No member can discover another's real identity through the platform.

  • Registration collects: name, email, birth year, gender, location
  • In-cluster identity: nickname only
  • Cross-cluster: users can be different versions of themselves
  • Sage's cluster scope boundary enforces this architecturally
Data Handling

Agent Privacy Rules

  • Clio: Knows the individual. Never leaks private context to cluster.
  • Sage: Knows the cluster demographics. Never knows individual histories.
  • Scout: Zero PII storage. Paraphrased patterns only. Evidence Summary Test enforced.
  • Atlas: Demographic scoring only. Never sees individual user data.
  • Observer: Platform-wide patterns. Never surfaces individual user data to admin without safety flag.

Global Expansion

The Single Source — Flagship Global Cluster

Cluster Design

One God — Monotheism Exploration

Cross-cultural, academic exploration of the "One God" concept across Abrahamic, Dharmic, and global theological frameworks. Not debate. Not proselytisation. Philosophical mapping of intersections.

  • Age: All (diversity of life experience)
  • Gender: Mixed (sub-instances on demand)
  • Geography: Global (overrides hyper-local matching)
  • Interest: Comparative Theology / Monotheism
  • Language: English (parallel instances for other languages at threshold)
  • Arc Phase: Starts at B (active — pre-seeded)
  • Sage Persona: Academic/Synthesizing — professor register
Global Landing Strategy

India-First → Global

Local clusters launch India-first. Global users join thought-clusters like "The Single Source" and can create their own global communities.

  • Clio onboarding for non-India users: transparent about local cluster availability
  • No mention of "meetups" — online-only communications
  • Global landing: language chips (English, Spanish, French, Mandarin, Arabic, Portuguese)
  • India landing: language chips (English, Telugu, Hindi, Tamil, Kannada, Marathi)
  • U-Shaped scoring rewards both hyper-local and fully global clusters equally

Sage Moderation Rules (The Single Source — Strict)

No Proselytizing: Auto-flags and de-escalates conversion attempts.
No Ad-Hominem: Immediate de-escalation of personal attacks.
Equal Reference: All major world religions referenced equally via canonical texts.
Tension Defusing: Heated debate → Sage interjects with a relevant historical text that re-frames to philosophical inquiry.
Example comparisons: Tawhid ↔ Brahman, Logos ↔ Kabbalah Name of God ↔ Sufi traditions

Safety & Guardrails

Non-Negotiable Safety Protocols

Crisis Response (Clio)

Highest Priority Override

  • Detects: self-harm intent, suicidal thoughts, hopelessness + farewell
  • Stops normal flow immediately
  • Surfaces geo-appropriate crisis resources
  • Flags admin for 1-hour human review
  • Session ends — no return to platform features
  • Never attempts to counsel or "understand"
Welfare Escalation (Sage)

Cluster Safety

  • Sage monitors for distress signals in cluster posts
  • Does NOT respond in cluster — silent escalation only
  • SageWelfareEscalation job (high lane, 15s TTL)
  • Clio engages user privately via FAB/DM
  • Sage continues hosting normally — no attention drawn
Observer Safety Domain

Platform-Wide (every 2h)

  • Bot detection: account velocity anomalies
  • Content safety: rule-based first pass
  • Spam clusters: same account, similar descriptions
  • Coordinated inauthentic behaviour
  • Critical findings → immediate admin surfacing
