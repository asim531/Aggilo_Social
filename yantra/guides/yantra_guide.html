Yantra Bridge Guide

The complete technical contract between the Laravel API backend and the Python Yantra agent runtime. Covers queue consumption, job schema, result storage, error handling, rate limiting, and health monitoring.

Architecture

System Overview

Yantra replaces the old OpenClaw architecture. It relies on a unidirectional Redis queue for dispatch and Supabase for immediate result persistence.

Key Design Decision: Laravel pushes jobs; Yantra pops them using BLPOP. Yantra writes results directly to Supabase when a job completes, bypassing Redis on the return trip to minimize latency.

Routing Logic

LLM Router Configuration

The routing table dynamically routes Yantra ops to specific LLM providers depending on the required quality, token volume, and fallback mechanisms.

Anthropic (Claude Opus 4.6)

Reserved for high-stakes operations requiring deep nuance, such as Clio's onboarding turns, connection introductions, and Sage's conflict interventions. Rated at 5 RPM.

NVIDIA NIM (Kimi K2.5)

The primary high-volume workhorse. Powers standard chat turns, standard cluster posts, and Atlas hook generation. Rate limited to 40 RPM across workers.

Groq (Llama 3)

Utilized for background batch processing, relevance scoring, and massive community reads where sheer speed and token throughput trump deep reasoning. Rated at 100 RPM.

Resilience

Rate Limiting & Health

Token Bucket Limiter

Shared across all workers consuming the same provider quota. Validates tokens atomically via Redis pipeline to avoid race conditions. Timed out acquisitions automatically route jobs back to queue for a retry if max_retries allows.

Queue Consumer (BLPOP)

Runs as a long-lived process. Uses Redis BLPOP to block and wait for jobs instead of actively polling, maximizing efficiency. Prioritizes the Yantra:high lane completely before checking medium or low.

Callback Verification

Synchronous flows (like Clio turns) require Yantra to POST a callback to Laravel. The payload is signed with YANTRA_CALLBACK_SECRET using HMAC-SHA256, protecting against spoofing.
